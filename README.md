# 刷题软件（第三期）

纯前端刷题小程序：**双击 `index.html` 即可用**，进度/错题/设置都存在浏览器本地，可离线运行；配好 API Key 后支持云端大模型 AI 解析与审阅。

## 打开方式

| 方式 | 操作 | 说明 |
|------|------|------|
| 普通使用 | 双击 `index.html` | 功能全部可用 |
| 安装到桌面（PWA） | `node server.js` 后浏览器打开 `http://localhost:8000`，地址栏点「安装」 | 独立窗口、离线可用 |

> PWA 需要 http 环境（`file://` 无法安装），所以安装到桌面要先跑 `node server.js`。

## 功能

- 首页板块入口 + 板块页「开始刷题 / 错题集」左右布局
- **答题逻辑**：点选项只选中，点「下一题」才显示答案与解析，再点一次跳下一题；多选漏选判错
- **错题集**：答错自动加入，按题型分类（选择/判断/填空/简答），可点「已学会」移出
- **PPT 式侧边导览**：半透明面板、可折叠，每页显示题干摘要，点击直达对应题
- **退出确认**：保存或重置该题库进度
- **云端 AI（设置里填 API Key 后启用）**：
  - 支持多家服务商：Anthropic（Claude）、DeepSeek、OpenAI，或任意 OpenAI 兼容接口
  - 「AI 解析」：点「下一题」显示答案时**自动**生成解析；解析过一次即缓存，之后直接显示，不再重复调用（省 token）
  - 「AI 审阅」：简答/填空题用大模型判分（无需与答案完全一致）
- 填空/简答另有本地相似度判分，离线也能用；简答可手动改判
- 响应式布局，适配电脑/平板/手机

## 配置云端 AI

1. 点左上角「⚙ 设置」。
2. 选择服务商（Anthropic / DeepSeek / OpenAI / 自定义），填入 API Key。
   - DeepSeek：默认模型 `deepseek-v4-pro`，接口 `https://api.deepseek.com`
   - 也可选「自定义」填任意 OpenAI 兼容的接口地址 + 模型名
3. 保存后，点「下一题」显示答案时会自动带出 AI 解析（缓存复用）；简答/填空题还有「AI 审阅」按钮。

> API Key 只保存在本机浏览器的 localStorage，由浏览器直接调用所选服务商的 API，不经过任何中间服务器。任何能访问该浏览器的人都能看到这个 Key，请勿在公共电脑上使用。

## 题库导入（开发用）

题库在 `js/data.js`，由 `gen_all.js` 从源文件自动生成（**请勿手改 data.js**）：

```bash
npm install xlsx adm-zip     # 首次需要
node gen_all.js              # 源文件路径在 gen_all.js 顶部 FILES 里配置
```

生成后，PWA 模式刷新页面即可（service worker 为「网络优先」，会自动拉到新题库）。
